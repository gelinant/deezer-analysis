# Test technique analyse de données Deezer

Version rendue au 16 septembre 2026


Vous trouverez dans ce repository l'ensemble des des fichiers ayant attrait au sujet d'analyse. 
Les deux fichiers principaux que vous voudrez étudier sont [le notebook final](demarche.ipynb) ainsi que le fichier [load.py](load.py) concenant la logique de load de la première partie.

Ce projet utilise uv pour la gestion des dépendances qui doit être installé sur la machine. 
Vous pouvez ensuite utiliser les commandes uv sync et uv run load.py (ou utiliser le notebook fourni) pour lancer le chargement des données depuis Deezer.
Le chargement prend entre 10 et 15 mn.
